# Ankita Singh Portfolio

React portfolio for Ankita Singh, focused on Lead Product Manager opportunities in B2B/SaaS and enterprise product leadership.

Live site target: `https://ankitasingh15.github.io/portfolio/`

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The resume download asset lives at `public/assets/Ankita-Singh-Resume.pdf`.

## GitHub Pages

This project is configured for GitHub Pages on the `ankitasingh15/portfolio` repository.

1. Push these files to the repository's `main` branch.
2. In GitHub, open **Settings > Pages**.
3. Set **Build and deployment > Source** to **GitHub Actions**.
4. Run the included **Deploy to GitHub Pages** workflow, or push to `main`.

The Vite `base` is set to `/portfolio/`, and the workflow builds and deploys `dist`.
